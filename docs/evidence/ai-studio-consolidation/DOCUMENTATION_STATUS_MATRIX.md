# Documentation Status Matrix

The searchable documentation surface uses structured records from `src/lib/aiStudioConsolidation.js`.

Required subjects covered:

- Marketplace
- Listings
- Rentals
- Sales
- Trades
- Swaps
- Brokerage
- Bookings
- Inspections
- Messaging
- Reviews
- Trust and verification
- Disputes
- Payments
- Escrow
- Roles and permissions
- Security
- Database
- APIs
- Testing
- Infrastructure
- Release gates

Allowed implementation labels are used: Active, Partial, Simulated, Specified Only, Credential Required, Infrastructure Required, Deferred, and Not Certified.
